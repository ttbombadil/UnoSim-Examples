# UnoSim Examples

Small Arduino Uno sketches consumed by UnoSim through the server-side HTTP
ExamplesProvider. The manifest is the public contract; every listed path is
relative to this repository and its immutable release ref.

The repository contains basic serial, LED, digital I/O, and multi-file header
examples. Releases should use immutable tags such as `v1.0.0`; production
UnoSim deployments may pin the corresponding commit SHA.
